# en-shorts

Automated builder for English short videos (survival scenarios and true stories) in flat 2D animation.
Scripts are written from official safety guidance (`content/en_survival.json`) and verified facts (`content/en_stories.json`),
voiced, animated with [Remotion](https://www.remotion.dev/) and queued in `queue/queue_en.json`.
Background music: Kevin MacLeod (incompetech.com), CC BY 4.0. Fonts: Montserrat, Oswald (SIL Open Font License).
